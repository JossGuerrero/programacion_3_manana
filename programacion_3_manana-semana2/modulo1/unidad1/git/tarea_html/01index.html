Componentes del SITM-Q

  • **Metro de Quito:** El sistema más nuevo y rápido.
  • **Trolebús y Ecovía:** Corredores de buses troncalizados.
  • **Buses Convencionales:** Rutas barriales y alimentadoras.
  • **Tarifas Integradas:** Opciones de pago unificado.
